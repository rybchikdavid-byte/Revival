# Revival

Своя песочница в духе 2016 года: базовая плита, блочный персонаж, скины,
ник на любом языке и мультиплеер по коду. Без аккаунта Roblox и без их серверов —
это отдельная игра, а не патченный клиент.

## Что внутри

- **Дизайн 2016** по умолчанию, кнопка **Design customization** в верхнем углу
- 21 стиль: 2006 → 2026, переключаются на ходу и запоминаются
- **Каталог** сбоку: футболки, штаны, лица, волосы + своя картинка (фото футболки)
- **Никнейм** на русском, английском, с пробелами и любыми символами
- **Мультиплеер**: «Хост» даёт код, второй игрок вводит его и оказывается в том же мире
- **Чат** внутри мира
- Загрузка мест **.rbxlx** (XML): плита, части, цвета, повороты
- Мир: 512×512 плита, бортики, пара построек, спавн

## Мультиплеер

Хост и игрок должны быть в одной Wi-Fi сети. Хост открывает порт, приложение
показывает код вида `RVL-XXXXX-XXXXX` — в нём зашиты адрес и порт. Аккаунт не нужен.

## Если что-то пошло не так

Revival больше не вылетает молча: ошибки ловятся, а лог пишется в **Downloads**:

- `Downloads/Revival-crash.txt` — причина падения и последние строки дневника;
- `Downloads/Revival-previous-run.txt` — если процесс умер, не успев сохранить лог;
- `Downloads/Revival-log.txt` — полный лог по кнопке «В Downloads» на экране лога.

После трёх неудачных запусков подряд игра открывает экран восстановления, а не
падает снова: оттуда можно открыть лог и запустить 2D-режим без OpenGL.
Экран лога также открывается из меню: **Settings → Crash log**, и из плашки
«⚠ Была ошибка» сверху.

## Сборка

Только через GitHub Actions: пуш в `main` собирает подписанный APK
(`Revival-apk` в артефактах).

## Чего здесь нет и не будет

Подключения к серверам Roblox, обхода их авторизации, чтения их каталога
и патча официального клиента. Мир, физика и сеть — свои.
